# SemanticSearch

A semantic search application that explores search beyond exact keyword matching by using meaning and context.

## Overview

SemanticSearch is a full-stack web project focused on retrieving relevant results based on the meaning of a query rather than only matching the exact words typed by the user.

## Key features

- Semantic search interface
- Search powered by an external search/indexing service
- Database-backed application
- Modern responsive web interface
- Type-safe development with TypeScript

## Tech stack

- Next.js
- TypeScript
- Prisma
- PostgreSQL
- Upstash Search
- Radix UI

## Getting started

### Requirements

- Node.js
- PostgreSQL
- Upstash Search credentials

### Installation

```bash
git clone https://github.com/shaloomniyibizi/SemanticSearch.git
cd SemanticSearch
npm install
```

Configure the required environment variables, then run:

```bash
npm run dev
```

Open http://localhost:3000.
